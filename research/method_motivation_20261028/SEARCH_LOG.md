## 分组与更新局部性的补充核查

为检查候选“面向更新的分组/重编译”是否只是已有参数隔离方法的改名，追加了有限的针对性查询，然后停止扩搜进入综合。

- `"parametric memory" "recompilation" update`
- `"LoRA" "memory" "partitioning" "updates"`
- `"parametric memory" "grouping" "facts"`
- `WISE Rethinking the Knowledge Memory for Lifelong Model Editing memory sharding merging`
- `SERAC Memory Based Model Editing at Scale counterfactual memory`
- `"SplitLoRA" "Balancing Stability and Plasticity"`

新核查的直接来源：

- [WISE 正文 v3](https://arxiv.org/html/2405.14768v3)：参数 sharding/merging 与作用域 routing 已有。
- [MEMOIR 正文 v1](https://arxiv.org/html/2506.07899v1)：样本依赖稀疏参数写入和相关知识激活已有。
- [SERAC 官方 PMLR PDF](https://proceedings.mlr.press/v162/mitchell22a/mitchell22a.pdf)：explicit edit memory、scope classifier 与 counterfactual model 已有。
- [ChunkWise LoRA](https://arxiv.org/html/2601.21109v1)：已读摘要/方法，针对推理序列动态 rank/scale/KV，不作为跨会话更新的直接证据，不引用性能数值。
- SplitLoRA 的 OpenReview 页面提取失败，已换用官方会议 PDF/ arXiv 检索线索确认主题；未完成正文审查，不作具体机制优劣判断。

这些结果进一步排除了“参数分块/隔离干扰本身是新颖点”的主张。未检索到相同命名不能作为本框架的新颖性证明。

- Cortex 的 arXiv HTML v1 返回 404，已改读同编号 PDF；版本页为 2026-10-14，PDF 正文标注日期为 2026-10-15，两者不能混作同一个日期字段。
- 多个 arXiv abs 提取结果缺少摘要正文，改用版本固定的 HTML/PDF；未将缺失内容补写为已核验。
- Towards Unified Memory Adaptation 仅取得 NeurIPS 官方摘要；同名 UniMem/Uni-Mem 必须按标题及编号区分。
